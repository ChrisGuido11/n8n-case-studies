Work

The headline number had no sentence behind it.

A draft was ready to present. The number sat in the title, where numbers sit when they want to be believed. There was no verbatim source. There was a paraphrase. “About four.” About four does not cover a precise figure, and it will not cover you when someone asks where it came from.

The old pass would have shipped it. A model will approximately confirm anything you stare at long enough. Confidence is a feeling. A quote is a sentence.

I strike the number. Each headline figure needs the source sentence in the source’s own words. If the checker cannot run — no source file, nothing to quote — the file is marked UNVERIFIED. I do not score confidence. I do not round a figure so the deck matches.

The client ships a sourced draft, or they fix the claim. Those are the two exits. There is no quiet pass.
