Work

They needed a room from a style line.

A merchandising team wanted a moodboard: one room, one line, furniture that belonged on the floor. The brief was ordinary. The first run was not.

The model ID was still listed. The node went red. Red looks like a bad credential. People reach for the header. The run was a 404. The model was gone. A pipeline that “just retries” would have picked a neighbor and shipped a room that looked close.

A later board came back looking finished. They had written “no floating furniture.” The image model has no negative prompt. The words did nothing. The chairs hung in the air and the file still smiled.

The turn was two rules. A dead model stops the run — loud, named, no silent fallback. And what you refuse has to live in the positive: furniture on the floor, in the prompt that the model actually reads. I never type Bearer into a header. That is a different ghost, and it wastes the afternoon.

The new rule: if the model is gone, the board does not ship. If the furniture must sit, you say sit — not “don’t float.”
