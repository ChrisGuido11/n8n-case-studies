A client needed a moodboard from a written brief. Not a chatbot that tries its best. A batch of images that match what they asked for, including what they forbade.

The node went red. Red looks like a bad credential. The instinct is to open the header field and type Bearer again. I never type Bearer into a header. The HTTP node already adds it. A double prefix fails quiet, and you spend the afternoon chasing the wrong ghost.

The run was not a credential problem. The run was a 404. The model ID was still listed. The model was gone. A pipeline that “just retries” will pick a neighbor model and ship a board that looks close. Close is a defect when the brief named a look.

A later attempt came back looking finished. The negative prompt had done nothing. Some image APIs ignore it and still return 200. A no-op negative is not a style choice. It is an unconstrained board with a pretty face.

I build the pipeline so a missing model stops the run, a no-op negative gets marked unconstrained, and auth stays out of the header field. The client gets a board that matches the brief, or a failure with a name. Not a pretty wrong board.
