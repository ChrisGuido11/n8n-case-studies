A headline percent appeared with no source.

A content draft was ready to present. The percent sat in the title, where numbers sit when they want to be believed. The rest of the page was careful. The headline was not.

There was no verbatim source. A silent fallback had filled the gap so the file would not look empty. “About this much.” About this much does not cover a precise figure, and it will not cover you when someone asks where it came from.

The turn is a strike. Each headline number needs the source sentence in the source’s own words. If the check cannot run — no file, nothing to quote — the draft is marked UNVERIFIED. I do not score confidence. I do not let a fallback finish the slide.

The new rule: every headline number needs a verbatim quote, or the file says it is unverified.
