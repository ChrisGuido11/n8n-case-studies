The model invented seven links.

A research pass is supposed to be boring. A list of sources goes in. Notes come out. Every citation is a URL someone actually opened.

Someone left off the =. In n8n, ={{ $json.url }} is an expression. Without the equals, the node does not resolve anything. It sends the literal characters {{ $json.url }}. The model received a template string and tried to be helpful.

Helpful was seven links that were never on the list. They looked like citations. They would have survived a skim. They would not have survived a click.

That is not a creative model. That is a wiring defect wearing a bibliography.

I count in and I count out. If a URL was not fetched, it does not appear. If the node sent a literal template, the run stops. The client gets a ledger — kept, dropped with a reason, failed — and notes written only from what came back. Invented citations do not ship.
